# Yardline Intelligence v0.4 — reported experiment results

## Status of this record

This report transcribes the v0.4 result summary supplied for the local research project. Raw experiment JSON and executable source have not yet been migrated into this repository. These are **reported results awaiting independent reproduction**, not results regenerated by this public repository.

- Target: weekly WR fantasy points, Half-PPR.
- Test season: 2025.
- Reported sample: 3,509 player-week observations.
- Reported weeks: 4–10.

## Interpretation

SMA-5 has the lowest reported MAE (2.6249) in this table. Adaptive Ridge has the highest reported Spearman value (0.5598) among the listed models and a Start/Sit value of 69.70%, but its MAE (2.6619) is higher than the SMA-5 MAE.

The original summary labels Adaptive Ridge as “+1.31%” versus baseline. That label is not consistent with a straightforward MAE comparison: 2.6619 is greater than 2.6249. The raw experiment output must be inspected to determine whether the label uses a different convention, whether a value was copied incorrectly, or whether the percentage is erroneous. This repository intentionally does not reinterpret it as a gain.

The earlier v0.3 reference result also identified SMA-5 as champion with MAE approximately 2.625.
