## Critical protocol caveat

The latest source pipeline still creates `store_select` from the 2024 selection dataframe and fits candidate models with `m.fit(store_select, ...)`. It does not fit those candidates on the declared 2018–2023 `df_train`. Thus, the reported run does not yet implement the declared 2018–2023 train / 2024 select / 2025 test protocol.

## Probabilistic interpretation

The residual pool is now populated, which fixes the previous zero-residual condition. The current run stores an empirical residual distribution. It does not yet establish calibrated player-level forecast intervals: the pipeline does not run the calibration evaluator, the forecast helper labels the 5th/95th residual percentiles as P10/P90, and the CRPS-labelled function is an approximation.
