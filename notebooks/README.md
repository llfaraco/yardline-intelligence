# Notebooks

Notebooks will be used for exploratory analysis, feature diagnostics and communicating model behavior.

Recommended sequence:

1. data coverage and source validation;
2. WR usage and target distributions;
3. rolling-feature and leakage diagnostics;
4. baseline performance by week and projection range;
5. residual analysis and model comparison;
6. contextual feature ablations;
7. predictive interval calibration.

Notebooks should load processed local data through documented paths. Do not embed raw datasets, credentials or private league information in notebook outputs.
